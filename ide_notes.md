# Git в VS Code и в терминале

Удобно в VS Code:

1. Панель Source Control показывает изменённые файлы, отдельный `git status` для этого не нужен.
2. Diff файла открывается кликом: видно, какие строки добавились и какие пропали.
3. Сообщение коммита пишется в поле над списком файлов, а не в отдельном редакторе вроде vim.

В терминале удобнее:

1. Отправлять ветку командой `git push`. На сервере окна VS Code нет, остаются только команды.
